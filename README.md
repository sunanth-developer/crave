# CRAVE Website - Riot Candy

Premium adult confectionery brand site for **CRAVE**.

## Stack
Vite + React + Tailwind CSS v4 + GSAP + Lucide

## Brand source
Guidelines + logo SVGs from `../CRAVE_Riot_Candy_Website_Kit/`.
Tokens: `src/styles/crave-brand-tokens.css`

Kit mascot/packaging JPGs are **reference only**. The site serves newly generated
WebP assets under `public/brand/mascot/` and `public/products/*/packaging.webp`.

## Commands
```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

## Waitlist
Set `VITE_WAITLIST_ENDPOINT` in `.env` to enable real submissions.
Without it, the form shows an honest unavailable state (never fakes success).

## Notes
- Packaging and mascot images are concept assets.
- Do not invent nutrition, health or availability claims.
- Logo SVGs are starter concepts - refine before trademark use.
