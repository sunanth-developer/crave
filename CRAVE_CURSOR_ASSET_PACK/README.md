# CRAVE Website & Cursor Asset Pack

This pack is a practical creative handoff for the existing CRAVE website.

## Start here
1. Read `05-guides/CRAVE-QUICK-BRAND-GUIDE.md`.
2. Open `06-cursor/CURSOR-MASTER-PROMPT.md` and paste it into Cursor with the existing website repository open.
3. Use `02-website/hero/CRAVE-hero-background-abstract.png` as the hero background.
4. Use the reference boards for visual direction only.
5. Use the packaging SVGs as editable concept mockups.

## Folder map
- `01-brand/logo/` — logo starter SVGs
- `01-brand/reference-boards/` — visual direction boards
- `02-website/hero/` — standalone abstract hero background
- `02-website/section-graphics/` — website reference boards
- `02-website/textures/` — reserved for future texture exports
- `03-products/packaging-concepts/` — four editable packaging front-panel SVG concepts
- `03-products/product-image-references/` — product range reference
- `04-graphics/stickers/` — reusable sticker SVGs
- `04-graphics/patterns/` — reusable pattern SVG
- `05-guides/` — brand tokens and guidelines
- `06-cursor/` — implementation prompt

## Important
This is a design concept/starter pack, not a complete commercial production package. The logo starter SVGs are not final custom lettering. Packaging SVGs are not print-ready dielines. Product imagery and flavour names are conceptual placeholders. Final packaging requires actual product specs, ingredients, nutrition, net quantity, FSSAI/licensing details, barcode, manufacturer details and regulatory review as applicable.
